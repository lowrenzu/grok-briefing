# Sources à connecter

Intégrations envisagées, non activées : notes Markdown de l'utilisateur, service météo choisi et documentation officielle sur l'accès et la réglementation. Avant toute connexion, vérifier l'actualité, la fiabilité, les licences de données et les conditions d'utilisation.

Aucune source externe n'alimente actuellement le cockpit. Voir [[Connexion météo]], [[Règles et sécurité]] et [[Données locales et vie privée]]. Les réponses doivent citer les sources réellement consultées.
